DigUp Test：中文界面测试版

适用：Apple Silicon Mac，macOS 14 或更新版本。

1. 解压下载的 ZIP，再解压其中的 tar.gz。里面是 DigUpTest.app 和测试说明。
2. 将 DigUpTest.app 保留在独立目录，不要覆盖原版 DigUp.app。
3. 界面跟随 macOS 的应用语言。可在“系统设置 → 通用 → 语言与地区 → 应用程序”选择 DigUp Test 的简体中文或英语，然后完全退出并重新打开。
4. 首次测试建议只选自己新建的测试文件夹，不要选原版的索引或模型目录。

这是开发测试包，采用临时签名，未经 Apple 公证。如果 macOS 阻止打开，请先保留具体提示，不要盲目修改安全设置。

本版的设置、索引、模型目录及辅助进程与原版隔离；自动更新已禁用。模型不包含在包内，首次使用可能需要下载。

新增内容：英文/简体中文界面、英文回退、状态与错误提示、数量和区域格式处理，以及随包携带的权限用途说明。中文检索修复沿用之前的测试版。

媒体检索与旧索引修复：
- 保留既有较强匹配，另列“较弱匹配与低可信度候选”；候选可能与查询无关，可展开查看。
- 已有有效向量可直接使用新的检索逻辑，无需删除测试版索引或全量重建。
- 旧版音频/视频若确有缺失向量或已保存的片段数量不符，会显示为失败，不会自动重新处理。请在设置中点击“重试失败的媒体”，补齐缺失部分；已成功处理的音频片段和视频帧会保留。
- 只检查已连接的所选文件夹。仅凭时长无法区分静音尾部和漏段；部分旧音频未保存预期片段数，不能自动确认。这些限制及受控测试结果见 MEDIA-RECOVERY.md。

自动测试结果和源码版本见 BUILD-INFO.txt；完整验收范围见 UI-LOCALIZATION.md。
尚未真机验证：实际界面排版、VoiceOver、系统权限弹窗的呈现，以及完整多模态检索质量。自动测试通过不代表这些项目已通过。
